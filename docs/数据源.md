# 数据源

> 自定义源怎么写、没配源时它怎么自己挑。实现见 [`intel/sources/`](../intel/sources)、
> [`intel/autosource.py`](../intel/autosource.py)。

## 1 自定义源

三类都可以自己加，不需要改代码：

| 类型 | 怎么加 | 适合 |
|---|---|---|
| RSS / Atom | 控制台「采集源 → RSS / Atom」一行一个：`名称 \| URL \| zh`；或改 `config.sources.rss` | 有 feed 的媒体、博客、官方公告 |
| 页面监控 | `config.sources.page.targets`（`{"name","url","selector"?}`），基线 + 文本 diff | 定价页、changelog、没有 RSS 的公告页 |
| GitHub / HN 查询 | `sources.github.topics / languages`、`sources.hn.queries` | 仓库与讨论 |

加源的三条纪律（都踩过坑）：

1. **URL 必须是 feed 直链**，不是站点首页。`https://36kr.com` 抓回来是 HTML，解析直接失败。
2. **写 `lang`**。不写按 `en` 算，中英配比会失真。
3. **单源默认只取前 10 条**，大源写 `"limit": 20`。

命令行体检与预览：

```bash
python main.py sources list                              # 现有源 + 兜底开关 + 上次自动选源结果
python main.py sources test https://example.com/feed.xml # 信任校验 + 真抓解析
python main.py sources auto --topic macro                # 没配源时自动挑，只预览
python main.py sources auto --topic macro --apply        # 写进 config.sources.rss（带备份）
```

## 2 自动选源（没配源时）

四类源**全部为空**才触发；只要配了任意一个源，它就不介入——不猜用户想要什么。

三层把关，缺一不可：

1. **目录**：内置 16 个分领域源（金融 / AI / 工程 / 医疗），各自带标签与 tier；
   没有模型时按标签命中数排序，有模型时让模型从目录里挑，允许补 1-2 个官方源。
2. **域名白名单**：只认 `DOMAIN_TIERS` 里的域名（政府 / 监管 / 公司官方博客 / 预印本 / 主流媒体 / 社区），
   子域按父域算。白名单外一律拒，理由写进 `data/auto_sources.json`；要放开得显式开
   `sources.auto.allow_unknown`（会降为社区级权重）。
3. **真抓校验**：每个候选都发一次请求并解析，404 / HTML 页面 / 空 feed / 坏 XML 全部拒。
   模型说「这是官方 RSS」不作数。

结果按关注范围指纹缓存 7 天（`data/auto_sources.json`），命中缓存不再调模型。控制台
「采集源 → AI 自动选源 → 现在挑一次」可以先看结果，再决定要不要「加入 RSS 列表」。

实测（真实网络）：金融主题挑出华尔街见闻 / CNBC / WSJ 三家，各验到 5 条；同一轮拒掉
arXiv（本机网络不可达）与 36kr（feed 已损坏）。

## 3 换领域时

默认 rss 列表全是科技源，只改关注项关键词会得到 0 条。实测可用的财经源、单源 `limit`、
双语关键词的必要性见 [配置与关注项 §3](配置与关注项.md)。
